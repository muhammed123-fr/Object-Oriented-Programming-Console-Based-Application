# E-Commerce Cart System (C# / OOP)

A Modular, Object-Oriented Programming (OOP) Console-based Application Built In C#. This Project Simulates Core E-Commerce Cart Management operations, product inventory updates, transaction logging, and basic administrative safety routines.

---

## Key Features

* **Cart & Product Management:** Add, Update, And Manage Item Quantities With Real-Time Stock Checks.
* **OOP Architecture:** Built Using Robust Object-Oriented Design Principles (Encapsulation, Inheritance, Abstraction, and Polymorphism).
* **Exception Handling & Logs:** Robust Error Handling For Payment Gateway Exceptions, Invalid Inputs, And Unexpected System States.
* **System Operations:** Includes Administrative Utilities Such As Cart Cache Resets And Transactional Rollbacks To Preserve Data Integrity.

---

## Built With

* **Language:** C#
* **Framework:** .NET Console Framework / .NET Core
* **IDE:** Microsoft Visual Studio
